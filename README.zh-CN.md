# 中文使用说明 · 0.5.5

应用自动维护本人邮件承诺，支持创建、改期、取消及排除无关邮件，保存原文出处与历史。当前不发邮件、不提醒、不观察其他应用。

在完整OctoSense宿主配置本人模型和邮箱。应用不收集密码或密钥。“启用观察与 AI 分析”只核验来源；再明确“同意本次云分析并开始”才读取正文并分析。应用打开期间每30秒检查最近5封，一次一封；关闭停止，重启默认停用。

记录标题、期限原文、证据、发件人、主题、日期及历史。改期保持id，取消显示“已取消（不代表完成）”；相对日期不伪造成绝对时间。

先停用再审查。上一条/下一条切换事项，详情显示证据与历史。“确认事项”只表示核对；“保存修正备注”接受非空最多300字，补充审查元数据，不修改原文证据或事项状态。

数据明文保存在隔离目录observer-state.json并读回核验；事项/去重各100条、历史20条上限。服务、输出或保存失败停止观察。已发出的宿主请求可能继续完成，不保证远端取消。

当前核心的五封真实POP3 TLS+MiniMax-M3回环、重复扫描和重启通过；[结果](validation/REAL_MAIL_0.5.5.md)。[异常矩阵](validation/LIFECYCLE_0.5.5.md)列明未覆盖项，不能把合成或静态检查冒充真实业务。

仅验证Windows、单一邮箱。网易126原RC2 IMAP缺客户端ID，本次使用POP3，未修复宿主。先让最新5封全部为本人测试内容再同意云分析；不要将私人邮件交给未接受的数据服务。产品API费用与Kimi/MiniMax开发套餐分离，没有免费默认模型。
