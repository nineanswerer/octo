# 真实邮箱与在线模型验收（2026-10-06）

0.5.4 使用官方宿主 mail/model 服务，读取 QQ 测试邮箱最近5封人工编写的验收邮件，由配置的在线 MiniMax-M3 判断，并读回本地记录。没有替换邮箱或模型服务响应。

| 邮件 | 观察结果 |
| --- | --- |
| 创建说明稿 | 生成一个事项 |
| 改期至10月8日中午12点 | 更新同一事项，保留旧证据 |
| 他人的预算事项 | 不增加记录 |
| 取消说明稿 | 原事项标为取消，保留两条历史，不当作完成 |
| 另一份截图清单，10月9日下午3点前 | 独立生成第二个事项 |

五封均标为已处理。停用后重启，状态文件字节摘要相同，观察默认关闭。此前0.5.3取消时出现错误事项编号，应用安全停止；本次修复限定模型可选编号并保留精确校验，之后成功处理剩余邮件。

[脱敏结果与源码/宿主摘要](real-mail-0.5.4-results.json)。修复还通过27项合成原生回归；合成回归和真实邮件结果是两类证据。

这是受控样例验收，不能保证任意邮件均正确识别，也不等于赛事晋级、App Hub 上架或全部 App Flow 已通过。宿主基于固定官方版本并含本地 Windows 邮箱凭据加密补丁，未宣称该补丁已被官方合入。邮箱地址、授权码、私人内容、原始模型请求及内部开发记录不公开。初赛冻结标签不修改。
